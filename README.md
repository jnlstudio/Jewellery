# JNL Studio Jewellery

Brand gateway for https://jnlstudio.github.io/Jewellery/

Plain HTML, CSS and JavaScript. No build step and no dependencies.

| To change | Edit |
| --- | --- |
| Wording and links | `index.html` |
| Colours, fonts and spacing | `:root` at the top of `styles.css` |
| Mobile menu and reveals | `main.js` |
| Photographs | `assets/img/` (keep the same file names) |

All local paths are relative, so the site works under `/Jewellery/`. Do not start them with `/`.

Only verified claims belong here. Use "gold tone" and "pearl-style" until materials are confirmed, and do not describe every product as handmade.

Old share links in the form `/Jewellery/#t=NAME` are forwarded to JNL Personalised by a small script in the `<head>` of `index.html`. Keep it.
